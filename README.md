# mail-from-the-two-of-us

**Correio de Nós Dois**: um PWA de cartas em envelopes físicos com QR code. Cada carta só abre
com o envelope na mão e no dia certo, graças a uma chave impressa no papel e a uma fechadura do tempo (timelock na drand).

O projeto está em [`correio-de-nos-dois/`](correio-de-nos-dois/). Lá estão as instruções de uso, deploy e o modelo de segurança.

```bash
cd correio-de-nos-dois
npm install
npm run dev
```
